## 同叫“香港月付”，差的到底是什么

第一层差别是带宽和流量怎么组合。香港市场目前有三种写法：

- **不限流量 + 小带宽**：野草云精品 BGP 的 2 核 1G 配 3M 不限流量，4 核 8G 配 8M 不限流量，年付标价 200 元和 792 元。3M 跑满一天也就 30GB 出头，所谓不限流量是建立在带宽很小的前提上。
- **大带宽 + 限月流量**：野草云优质 BGP 给 500Mbps 峰值配 600GB–1.5TB 月流量；LightLayer 的香港入门款是 1TB 流量。峰值带宽好看，跑超了要么限速要么加钱。
- **大带宽 + 不限流量**：eServer 的 Business Plus 是 1Gbps、不限流量、HK$770/月。这个组合才配得上“不限流量”四个字，价格也摆在那里。

看到“不限流量”，先找带宽数字；看到“100M”“500M”，先找流量上限。两个数字缺一个，这条参数就没法用。

第二层差别是线路。eServer 在 VPS Start 和 VPS Lite 的配置栏里直接写“没有直接到中国的互联网”，这是本次核验里对决策最有价值的一句话。它说明低价香港机卖的是香港本地和国际出口，不是到大陆的优化线路。LightLayer 把带宽拆成“优化、全向、国际”三档，也是同一件事：同一台机器走不同出口，价格和体验都不是一个产品。

第三层是硬件代际。LightLayer 香港独服目录里 E3-1230、E5-2660、Gold 6138 三代平台同时在售，报价从 56 美元到 120 美元，差价主要在平台和带宽方案，不在硬盘大小。

## 常见问题

**月付的机器能随时退吗？**

看条款，不看“月付”两个字。云服务器常见 3 天无理由，超期按剩余折算或直接不支持；物理服务器和活动特惠机通常更严。LightLayer 的具体条款在下单流程里，付款前看一眼比事后争辩有用。

**年付比月付便宜多少？**

以上面算的 1 核 2G 为例，年付 365 元对月付 456 元，省 91 元，约 20%；月付一年多付约 25%。跑满一个月验证过再转，是唯一稳妥的顺序。

**“不限流量”是真的不限吗？**

流量不限的机器通常带宽很小。3M 带宽跑满一天 30GB 出头，8M 也就 80GB 左右。要 500Mbps 峰值，就得接受 600GB–1.5TB 的月流量上限。两个参数一起看才成立。

**便宜的香港套餐为什么延迟高？**

线路不同。低价款可能根本不走大陆优化出口，商家自己会在配置栏注明。买之前确认线路标注，别只看“香港”两个字。
